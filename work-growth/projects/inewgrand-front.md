# inewgrand-front

## 项目定位

产业信息平台前台项目，承载用户侧的登录注册、租户开通、应用市场、订单确认、支付凭证、发票信息、产品展示、N-Claw 充值和 Sentry 接入等链路。

## 关键问题

- 前台需要从基础页面推进到可支撑应用市场、租户、订单和支付的完整业务链路。
- 多环境部署涉及 API baseURL、OSS/CDN、图片资源、Sentry 隧道等配置，需要降低环境差异导致的问题。
- N-Claw 充值和支付链路涉及订单创建、协议确认、支付渠道识别、二维码展示、跳转、缓存和页面状态，需要保证用户路径顺畅。
- N-Claw 推广页和首页产品展示需要兼顾大图资源、iframe 容器、视口缩放、移动端导航和响应式布局，避免产品入口在不同设备上失真。

## 可复用经验

- 交易类前台链路要把“下单、支付、状态、凭证、错误处理、跳转”作为一条完整路径设计，不宜只看单页面功能。
- 多环境配置必须收敛到明确的环境变量和运行时规则，避免在业务组件里散落判断。
- 对图片、上传、金额、验证码等高复用能力应优先组件化或工具化。
- 推广页或 iframe 页面要提前处理视口缩放、容器高度和资源加载，不然在嵌入场景中容易出现裁切或留白。
